KUMM — Krinik Universal Mod Manager — an engine, a framework and a set of tools for a semi-automated process of building games with mods.

Nikolai plays Palworld and will later play Oblivion Remastered. KUMM helps to assemble a build of favourite mods into an updated pirated copy of the game automatically, to update the mods, fix their compatibility problems, and optimise the mods and the game engines.
