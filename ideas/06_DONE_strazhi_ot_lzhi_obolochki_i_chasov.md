# Идея 06 — Два стража: код с обратным слэшем не ходит через heredoc, штамп времени не обгоняет часы

## Вектор цели

Тип цели — **Avoid**. Боль: два класса ошибок агента на этой машине повторяются, хотя записаны и в журнале
опыта, и в памяти. По канону «два промаха → механизм, а не третье напоминание».

1. **Обратный слэш теряется в bash-heredoc.** Записано 2026-08-21 (`EXP-0029`), лежит в памяти агента, и всё
   равно повторилось 2026-09-18: скрипт слияния навыков, написанный через heredoc, превратил
   `.\Deploy-ModPack.ps1` в `.Deploy-ModPack.ps1`. Поймано чтением результата, в дерево не попало.
2. **Штамп времени или число вписываются раньше наблюдения.** За одну сессию 2026-09-18 — четыре раза: числа
   в шапке стража до его прогона, время закрытия тикета 02, время поправки в тикете 03 и время отчёта
   прогона (оба вперёд часов), упоминание «прогона 4» до самого прогона. Два случая поймал я сам, два —
   независимый судья.

## Критерии приёмки

- Ситуация. Агент в этом проекте вызывает инструмент Bash с heredoc, в теле которого есть символ `\`.
- Действие. Харнесс запускает хук перед вызовом инструмента.
- Результат. Вызов отклонён, агент видит строку: «в теле heredoc есть обратный слэш — пиши файл инструментом Write».
- Проверка. `echo '{"tool_name":"Bash","tool_input":{"command":"cat > x.mjs <<EOF\nconst p = \"a\\\\b\";\nEOF"}}' | node tools/hooks/no-backslash-heredoc.mjs` завершается кодом 2 и печатает эту строку; тот же вызов без `\` в теле — код 0.

- Ситуация. В индексе git лежит новый или изменённый документ, где стоит штамп сегодняшнего дня с временем позже текущего, например `2026-09-18 18:35` при часах 18:18.
- Действие. Владелец или агент запускает `git commit`.
- Результат. Коммит остановлен, напечатаны файл, строка и оба времени.
- Проверка. `node tools/check-future-stamps.mjs --staged` на таком файле завершается кодом 1; на файле со штампом в прошлом — кодом 0.

## Что именно предлагается

1. `tools/hooks/no-backslash-heredoc.mjs` — хук `PreToolUse` для инструмента Bash, около тридцати строк.
   Подключение — одна запись в `.claude/settings.local.json` этого проекта. **Это правка ваших настроек
   харнесса — поэтому идея, а не коммит.**
2. `tools/check-future-stamps.mjs` и его вызов из `tools/hooks/pre-commit` рядом с обезличиванием. Ловит только
   штампы ВПЕРЁД часов: штамп в будущем выдуман всегда, а вот штамп в прошлом машина от честного не отличит —
   эту половину по-прежнему держит судья.

## Риски

- Хук будет мешать законному heredoc с `\` в теле, которое агент потом читает обратно. Цена — один лишний
  вызов Write; это и есть цель.
- Второй страж не видит штампов без даты и штампов в таблицах с иной формой записи — граница названа, не скрыта.
