## Что это

Карта мира размечается на области (зоны). У каждой зоны — **набор тегов**, а не один тип: теги описывают, что в этой области есть.

| Пример владельца | Теги зоны |
|---|---|
| озеро в лесу | [Вода] [Лес: …] |
| скалы в пустыне | [Скалы] [Песчаная пустыня] |
| заснеженный лес | [Снег] [Лес: Хвоя] |
| заснеженное озеро | [Снег] [Вода] |

Теги, названные владельцем: [Вода], [Лес: лиственница], [Лес: Хвоя], [Лес: смешанный], [Песчаная пустыня] — «и так далее»; [Скалы] и [Снег]
следуют из его примеров. Полный словарь тегов — решение владельца (`[AI]` предложу список по карте игры, когда начнём разметку).

## Зачем (что даёт разметка)

1. **[Вода] → путники не ходят по дну** (баг 38): по контурам зон с [Вода] мод ставит препятствия навигации с вырезом (`NavMeshObstacle`,
   carve) — путь обходит воду, перепекать навигацию не нужно.
2. **Карта температур** (список владельца): температура зоны от её тегов ([Снег], [Песчаная пустыня]…).
3. `[AI]` Дальше по тем же тегам — звуки, погода, кто где живёт (живой мир, KARMA): одна разметка на всех потребителей.

## Чем проверим, что сработало

- Situation. На карте размечены зоны вокруг пруда у деревни (сейв владельца), пруду дан тег [Вода].
- Action. Путник дня из Бары идёт по своему распорядку мимо пруда.
- Result. Высота путника на всём пути не ниже берега (90.1): по дну не идёт, обходит воду.
- Check. Трасса пульта `callon "<путник>" Transform get_position` каждые 2.5 с — минимальная высота ≥ 89.5.
