## 2. Цвета «название — число»

`[OWNER]` «нужно текст свойства одним цветом, а цифру каким-то другим, чтобы выделять их. Аналогично в инвентаре с цифрами
статов героя» · ≈08:26; «этот жёлтый цвет мочи некрасивый» · ≈08:03.
`[AI]` Предложение: число выделяется светлотой и весом, а не жёлтым — название приглушённое тёплое `#B9AF9D`, число светлое
`#F4EEE3` SemiBold. Варианты покажу кадром до правки всех экранов.

## 3. Проход по каждому экрану (отметить каждый пункт)

- [ ] **Шрифт** — весь текст Manrope; кадр + `dump` пульта: ни одного `font=` кроме Manrope.
- [ ] **Вес по роли** — заголовки Bold, названия SemiBold, текст Medium (раздел 1); жирного «на всё» нет.
- [ ] **Размер по шкале** — каждая строка попадает в свою ступень раздела 1; соседние ступени различимы глазом.
- [ ] **Название / число** — разными цветами и весом (раздел 2); жёлтого «цвета мочи» нет.
- [ ] **Ничего не обрезано** — В3: значения не уходят за край («Железный ч…» в «Прогрессе» — пример провала).
- [ ] **Ничего не налезает** — В4: заголовок не перекрывает текст («Божье вмешательство» на странице бога — пример провала).
- [ ] **Колонки** — названия по одной левой линии, числа по одной линии (В5); между колонками — воздух, а не впритык.
- [ ] **Поля** — В1: текст не касается края подложки.
- [ ] **Межстрочный** — Т5: около 1.5 в абзацах, без пропусков «в целую строку».
- [ ] **Контраст** — Т2: не меньше 4.5 : 1 (`tools/contrast.py`).
- [ ] **Регистр** — только первая буква заглавная («Критический удар», не «Критический Удар»); капс — короткие ярлыки (Т8).
- [ ] **Термины** — одно слово на одно понятие во всех окнах (сейчас «Молоты» в статах и «Дробящий» в карточке предмета).
- [ ] **Курсива нет** — Т3.
- [ ] **Композиция** — баланс, пустоты, всё «прилеплено»; сравнение с образцом жанра из `gallery/refs/` (рулбук, раздел 10).
- [ ] **Кадр «было → стало»** — в `SvarogsDream/gallery/game/<дата>_<экран>/` с историей; затем — взгляд владельца.
