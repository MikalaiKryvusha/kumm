## Root cause

- П. 1, 4: направление разбега бралось из `agent.velocity` в миг отрыва. Упёршись, агент стоит (скорость 0 — прыжок вверх); у препятствия
  агент обходит его и скользит вдоль борта (прыжок вбок).
- П. 3: в `Step` при касании стены скорость проецировалась на плоскость, но подъём обрезался `v2.y = min(v2.y, vel.y)` — разбег не
  уводил вверх вдоль склона круче 50°, герой сползал.
- П. 2: герой ходит по навигационной сетке; у края склона сетка кончается — сойти с неё нечем, кроме прыжка. Нужен сход с сетки через край.

## Fix (SvarogsDream `src/KrinikFixes/Jump.cs`)

- П. 1, 4: нажаты WASD — направление клавиш от камеры, как в `PlayerController.HandleKeyboardMovement` (клавиши действий 29–32, без
  левого Alt), скорость — `agent.speed` этого кадра (игра пишет её и тогда, когда герой упёрся); без клавиш — взгляд героя
  (`player.forward`) со скоростью агента. Журнал: `run … (wasd|facing, N deg off agent velocity V)`. FORK: options <agent.velocity |
  взгляд | WASD> · price of error <прыжок не туда> · consulted <слово владельца «следовать направлению… по wasd»>.
- П. 3: подъём вдоль склона больше не обрезается (`ProjectOnPlane` без ограничения); отвесная стена подъёма не даёт по геометрии.
