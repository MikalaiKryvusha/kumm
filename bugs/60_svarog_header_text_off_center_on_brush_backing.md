## Symptom

Заголовок «Список квестов» (Manrope, светлый) на тёмном мазке кисти: верх букв на середине мазка, низ ниже мазка; по горизонтали текст смещён
вправо от середины мазка. Ожидается: текст по центру мазка по вертикали (середина строчных букв — на середине мазка) и с равными полями слева и
справа — как у заголовков, где это уже сделано (сверить «Отношения» на жёлтом мазке из кадра бага 56: там текст по середине).

Слово владельца во множественном числе — «в заголовках»: класс, не один экземпляр. Перепись всех заголовков на мазке — первым шагом.

## Hypotheses

1. Мазок — картинка игры с размером под английский шрифт игры; наш Manrope (Т3) с другой высотой строки и выносными элементами — текст по
   прямоугольнику надписи встаёт ниже середины мазка.
2. Ширина мазка не подстраивается под русское название (В2) — текст длиннее и уходит вправо.

## Fix plan

Перепись: все объекты «надпись на мазке» во всех окнах (дамп пультом по спрайту мазка) → одна функция: мазок по ширине текста с полями, текст по
вертикали по середине нарисованных строчных букв (как `DigitDropK` у цифры перезарядки — замером, не на глаз) → кадры всех найденных заголовков.
