# Bug 50 — камера покачивается вместе с дыханием героя

**Status:** 🔧 починено 2026-10-14 23:12, ждёт глаза владельца — гипотеза 1 доказана замером (размах камеры 0,0419 → 0) · **Severity:** S2 · **Version/build:**

## Symptom — слова владельца дословно

`[OWNER]` «бесит, что при дыхании героя, камера за ним следует, чуть-чуть дергается» · «при дыхании героя, его фигурка чуть-чуть
покачивается, и камера тоже» · 2026-10-14

## Root cause / Hypotheses

1. `[AI]` (по коду, не наблюдено): `Lift` раз в `HeadMeasureSeconds` (2 с) меряет рост героя по кости головы
   (`anim.GetBoneTransform(HumanBodyBones.Head)`), а кость ходит с анимацией дыхания. Каждый замер ловит другую фазу вдоха, и точка
   взгляда плавно (`MoveTowards`, `LiftSpeed`) съезжает к новому числу — камера качается вместе с героем. Комментарий в коде сам говорит:
   «Кость головы ходит с анимацией (присел, удар)».
2. `[AI]` Цель камеры игры (`CameraFollow.target`) сама привязана к анимированной кости — тогда покачивание есть и без нашего мода
   (проверка: `LookAboveHead` = −1, «как в игре»).

## Repro / проверка (план)

Герой стоит у костра 20 с; пульт пишет высоту камеры каждый кадр (или строку `HeadStatus` раз в кадр) — размах по вертикали при
`LookAboveHead` 1 и при −1. Ожидание после правки: размах ≈ 0 при стоящем герое.

## Fix plan

Рост героя — не по кости в случайной фазе дыхания: брать наибольшее за окно замеров (или коллайдер/рамку), менять точку взгляда только
при сдвиге больше порога (экипировка, ездовое), а не на каждое дыхание. Кейс — в `testcases/` до правки.

## Fix (2026-10-14, SvarogsDream KrinikCameraRework)

`Lift`: новая цель точки взгляда — только если рост сдвинулся больше `LiftDeadZone` (5 % роста); дыхание её не двигает. Замер в одном
запуске (`testcases/TC_svarog_native_refactor_batch2_2026-10-14.md`, S3; отчёт `testcases/reports/2026-10-14_svarog-refactor-batch2.md`):
порог 0 (как до правки) — 850 кадров, размах камеры по вертикали 0,0419, кость головы 2,787 ↔ 2,764; порог 0,05 — 859 кадров, размах 0,0000.
Гипотеза 2 (цель камеры игры на кости) этим не проверена: при `LookAboveHead` −1 замер не работает. Пульт: `call KrinikCameraRework.Plugin
CamSwayStart 10` → `CamSwayResult`.

## Decisions made without the owner

`[AI]` порог 5 % роста — больше размаха дыхания (≈ 0,8 % по кости), меньше смены экипировки и ездового; меняется словом владельца.
