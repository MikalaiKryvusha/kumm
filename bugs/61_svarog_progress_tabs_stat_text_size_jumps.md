# Bug 61 — «Прогресс»: у вкладок «Персонаж» и «Кампания» разный размер текста статистики, при переключении статистика прыгает

**Fixing:** this session — после багов 55–60

## Symptom

Окно «Прогресс», вкладки «Персонаж» и «Кампания»: строки статистики «название: значение» на одной вкладке одного кегля, на другой — другого;
при переключении вкладок колонки и строки сдвигаются. Ожидается (К2): кегль и ширины колонок — одни на обе вкладки, по самому длинному случаю;
разброс координат строк ≤ 2 точки на 4K при переключении.

## Hypotheses

1. Кегль подбирается по содержимому каждой вкладки отдельно (`ProgressLayout.cs` / палитра «Прогресса») — вкладка с длинным названием ужимается.
2. Колонка значений ставится за самым длинным названием СВОЕЙ вкладки — у «Кампании» другое самое длинное название, колонка прыгает.

## Fix plan

Дамп обеих вкладок (`size` всех строк, x колонки значений) → один кегль и одна колонка по самому длинному названию обеих вкладок → кейс К2: дамп
после каждого переключения, разброс ≤ 2; кадры листом.
