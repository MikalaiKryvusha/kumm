# Bug 62 — летопись событий: строки записи с лишним пробелом в начале, список слева без поля, «Ема» и «Эма» в одной записи

**Status:** 🔴 OPEN
**Severity:** S2 (рулбук В1, В5, Т7; имя героя написано двумя способами — класс бага 28/перевода)
**Version/build:** KrinikUIRework сборки 2026-10-18 13:32 · **When/context:** 2026-10-18 ≈13:41, владелец в игре агента, кадр окна событий (список
«Новый персонаж / Смерть персонажа / Мировое событие» слева, запись «Новый персонаж» справа): `[OWNER]` «плохое выравнивение текстов по левому краю»
**Fixing:** this session — после багов 55–61

## Symptom

1. Запись справа: «Новый герой: Ема, 37 лет.» с левого края, а «Предыстория:» и «Эма когда-то мечтала…» — на пробел правее; дальше строки снова с
   края. Строки одного абзаца не на одной левой линии (В5). Похоже на лишний пробел после перевода строки в склейке текста.
2. Список слева: «Новый персонаж», «Смерть персонажа» прижаты к левому краю полосы без поля (В1 — поле не меньше ¾ высоты строки).
3. В одной записи имя героини дважды по-разному: «Ема» (строка игры «Новый герой: …») и «Эма» (наша биография) — одно имя, одно написание.

## Hypotheses

1. Склейка записи игры: `"Новый герой: " + name + "\n Предыстория:\n " + bio` — пробел после `\n` в шаблоне игры или в нашем переводе шаблона.
2. Список — кнопки игры с выравниванием влево без отступа; наш стиль меняет шрифт, но не поле.
3. Имя: перевод имени в строке игры («Ema» → «Ема») и в биографии (`hero bios`, «Эма») из разных словарей — правило транслитерации «E → Э» в
   начале имени не одно.

## Fix plan

Дамп записи (сырой текст с пробелами) → убрать пробел после переноса там, где он рождается (перевод шаблона или текст игры при показе) → поле
слева у списка (одна норма полей, В1) → одно написание имени во всех словарях (перепись имён героев на «Е/Э» в начале) → кадр записи и списка.
