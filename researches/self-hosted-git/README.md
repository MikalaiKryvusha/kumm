## Итог

Переезд на GitLab.com выигрыша не даёт. Если цель — не зависеть от санкционных правил США и от лимитов чужого сервиса, надёжнее свой
сервер Forgejo или Gitea на этой машине, с отдельным диском и копией. GitHub остаётся витриной для публичных проектов: KUMM, KARMA,
исток KAIF.

## Свой сервер

- **Чем.** Forgejo или Gitea: один исполняемый файл или контейнер, мало памяти, веб-интерфейс как у GitHub, задачи, запросы на
  слияние, LFS. GitLab CE умеет больше, но требует заметно больше памяти.
- **Где.** Отдельный диск в этой машине — если пользоваться самому и с неё. Для доступа с других устройств при выключенном
  компьютере нужен маленький отдельный компьютер или NAS, который не выключают.
- **Копия обязательна.** Сервер — единственная копия; второй носитель или зашифрованная облачная копия по расписанию.
- **GitHub — зеркало** для того, что должно быть видно людям; основной сервер — свой.

## Диски под это (машина владельца, опрошено 2026-10-25)

Плата ASUS TUF GAMING B550M-PLUS (WI-FI), процессор Ryzen 7 5700G — слотам M.2 только PCIe 3.0. Диски сейчас: `C:` Kingston A2000
500 ГБ (NVMe, слот M.2), `D:` NE-1TB (NVMe, слот M.2), `E:` `F:` `J:` — три SATA по 1 ТБ.

- **Новые M.2 под `C:` и `D:`** — PCIe 4.0 (Samsung 990 Pro, WD SN850X, Kingston KC3000) с заделом под новую плату; сейчас работают на
  3.0. PCIe 5.0 сейчас — переплата.
- **Перенос один в один** — клонирование через USB-корпус для NVMe (Samsung Data Migration, Acronis для Crucial/WD, Hasleo Disk
  Clone, Clonezilla), затем растянуть раздел. Windows на новой плате обычно загружается сама; лицензию, возможно, активировать заново.
- **Старые NVMe в переходник «на SATA» не встанут** — такие переходники только для дисков M.2 SATA. Для NVMe: плата-переходник M.2 →
  PCIe во второй длинный слот (`PCIEX16_2`, чипсет, x4; у соседних плат ASUS падает до x1, если занят короткий слот x1 — проверить
  в инструкции) или USB-корпус.
- **`PCIEX16_2` перекрыт видеокартой** (слово владельца 2026-10-25: «во второй длинный слот PCIEX16_2 - у меня его GPU перекрывает») —
  плата-переходник отпадает. Совет: один новый M.2 на 2 ТБ под `C:` (клон A2000), NE-1TB остаётся под `D:`, гит — на SATA 2.5" внутри
  (если свободен четвёртый порт SATA; проверить, не отключает ли занятый второй M.2 пару портов SATA), A2000 — в USB-корпус как
  внешняя копия гита. Корпус сначала служит для клонирования.
- **SATA 2.5" под гит:** память TLC и DRAM-буфер — Crucial MX500 (на OZON 2 ТБ — 1 112 р., слово владельца), Samsung 870 EVO
  (Onliner: 2 ТБ — 1 790 р.), Kingston KC600. Без DRAM, но на TLC, для гита тоже годятся: Netac N600S, Team GX2, Patriot P210. Не брать
  QLC (Crucial BX500, Team QX) и безымянные бренды с AliExpress.
- Фильтр Onliner (TLC, DRAM, надёжные бренды, 1–4 ТБ, по цене) — ссылки в чате 2026-10-25; у Onliner галочка DRAM стоит не у всех
  моделей с DRAM (Kingston KC600), поэтому фильтр неполный.
