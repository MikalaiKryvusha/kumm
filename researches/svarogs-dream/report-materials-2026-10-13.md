## Сводка 1 — как игра устроена (researches/svarogs-dream/*.md)

### Движок и поверхность модов
- Unity 2020.3.49f1, Mono (не IL2CPP), встроенный конвейер, Post Processing v2; камера Deferred, HDR, линейный цвет, туман выключен (README.md, sky-recon.md, main-thread-recon.md).
- Весь код — `Assembly-CSharp.dll`, имена читаемые, патчится по имени. Главная сцена `level1` 244 МБ, бандлы Addressables; всего 5,8 ГБ (README.md).
- Загрузчика модов в игре нет; Harmony/MonoMod/ReiPatcher в поставке есть. Локализации нет: строки — английские литералы, русский подставляет XUnity (README.md).
- Внешних модов нет: Мастерской нет, на Nexus нет, только трейнер (досье). Burst нет; Job System доступна (main-thread-recon.md).

### Мир и симуляция
- Невидимой симуляции нет: каждый житель — полный объект сцены (`CharacterStats`, `NPCController`, `AIDecisionMaker` помнит врагов до 70 м, `AIDailyRoutine`, `NavMeshAgent`, аниматор) (simulation.md).
- Мозг каждый кадр, приоритеты: домой → бегство/бой → наёмник/охотник → приветствие → задание → помощь → распорядок → прогулка (simulation.md).
- NavMesh один на мир, запечён — путники ходят по дну пруда (simulation.md).
- 1 игровой час = 60 с; у жителя таблица на 24 часа (simulation.md).
- Подгрузка: участки 300×300 м, решение раз в 0,5 с, квадрат 3×3; за квадратом всё выключено вместе с жителями (simulation.md).
- Без героя мир пуст: живут только данные — товар в 6:00, события мира раз в 200–300 с, битвы фракций ближе 150 м (simulation.md).
- Путники: 35 типов, расписание по дню 0…6, дальше 100 м без модели, дальше 500 м исчезают; целей и памяти нет (simulation.md).
- Отсечения аниматоров нет: у 425 из 446 «двигать всегда» (simulation.md). Зоны: только города и метки звука участков (world-zones.md).

### Прокачка
- 11 растущих величин (Сила, Ловкость, Интеллект, Выносливость, Храбрость, Алхимия, Рыбалка, 4 мастерства); потолок 100 в `GetCurrentLevelMultiplier` (progression-uncap.md).
- Потолки от талантов 90–150, лёгкая +20, Полубог Перуна +200. Уровень души без потолка; опыт `850·L+300` … `5000·L` с 90-го (progression-uncap.md).
- Очки умений `4+3·L`, на класс не больше 25; формулы линейные: Здоровье `50+10·Сила+20·Выносл.`, Мана `60+12·Инт.`, вес `100+2·Сила` (progression-uncap.md).
- Враги обрезаны уровнем 70, боги 85–125; масштабирование мира только в режиме «Insane + Against Odds» (progression-uncap.md).
- Ошибки автора: Flamekeeper от очков Marksman; звериная ярость дважды прибавляет рубящий урон; дробящее качает Ловкость (progression-uncap.md).

### Предметы
- 721 предмет; 20 числовых строк; качество 0–12: урон +5 %, вес −5 %, крит +2 за ступень, +100 только на 8-м (item-properties-recon.md).
- `CustomEffect` — только текст; настоящий эффект — перечисления (`enchantmentElement` 70 значений и др.), эффект у 253 из 721 (item-properties-recon.md).
- Удар: блок → броня → разброс ±10 % → крит ×2; скорость атаки `0,5+Ловк./50`; камуфляж — конус зрения 120° минус камуфляж (inventory-stats-mechanics.md).

### Время, погода, вода
- `WorldTime`: день 5–22 ч, зимой 7–20; ночь — только яркость света и виньетка; лиловый оттенок — профиль `FinalVersion5` (sky-recon.md, README.md).
- Погода раз в час, только после квеста `Thunder`: зимой снег 10 %/ч, иначе дождь; тумана как погоды нет (world-zones.md).
- Вода — Lux Water, отражает только небо (`reflectionMask = Nothing`) (water-recon.md).

### Производительность
- Однопоточная: потоков, `Task`, `IJob` — 0; главный поток 69–81 %, ядер 1,9–2,1 из 16 (main-thread-recon.md).
- Скрипты ≈3 мс из 28,9; основная цена — движок вокруг жителей, ≈12 мс на 400 жителей (main-thread-recon.md).
- `WaitForSeconds` 1905 мест, `GetComponent` 1146; `CullingGroup` и `LODGroup` — 0 (main-thread-recon.md).
- Без модов главный поток 21 мс (≈47 FPS, 4K); наши моды +0,2 мс CPU, +2 мс GPU (досье).
