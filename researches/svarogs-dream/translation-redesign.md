## How it works now

- XUnity.AutoTranslator hooks every UGUI/TMP text. Lookup order: `Translation/ru/Text/*.txt` alphabetically, a later file
  overrides an earlier one — `_AutoGeneratedTranslations.txt` (masterkosta's dictionary + everything DeepL returned at runtime),
  then our `zz_krinik.txt` (deployed from `SvarogsDream/_config/xunity/zz_krinik.txt`).
- Miss → `Endpoint=DeepLTranslate` online; the answer is cached INTO `_AutoGeneratedTranslations.txt`.
- Font: `OverrideFontTextMeshPro=krinik_manrope` (since 2026-10-06; was `rus_font` = Shentox).
- `EnableUIResizing=True`, `ForceUIResizing=True`, `ResizeUILineSpacingScale=0.80`.

## What hurts (measured)

| Finding | Evidence |
|---|---|
| Online answers are cached per number combination and translate the term differently each time | 85 lines `<Blunt/Slashing/Piercing/Magic> <Armor/Damage/…>`; «Slashing Armor: 5 (-4)» = «КОЛЮЩЕЕ оружие броня» (it is slashing), «Piercing Armor» = «Острое оружие броня» / «Пробивающая броня», «Blunt Damage» = «Тупой урон» |
| Field-width truncations baked into the dictionary | `tools/translation_quality.py`: 114 stub candidates checked against the pymorphy3 Russian dictionary — «Закл порядка», «Восст 20% макс здоровья», «MP Реген», «Оруж ближ боя», «Любимая способн», «Самый больш урон» (false positives: names — Велес, голем, элементал) |
| A full-word fix can collide with the field | «Заклинания Порядка» lay over «20 %» on the Mastery tab (frame ms0) → shortened to «Порядок:» (frame ms1). Every translation fix must be looked at in the game |
| Title Case in 447 short Russian strings | count only; our own block in `zz_krinik.txt` declares «term of 2+ words — every word capitalised» (approved list 2026-10-04) — the owner's call |
| `ForceUIResizing` was suspected of moving our Progress layout | **Refuted** 2026-10-06 09:31: with `ForceUIResizing=False` the number «69» still drifted 2472 → 2541 (log `progress drift (hold off)`); config restored to `True`. ## Proposals (ranked; each reversible)

1. **Turn the online endpoint off** (`Endpoint=`): no new DeepL junk enters the cache; a miss stays English until our pass
   translates it. Cost: new strings show English. Owner's call — it changes what he sees.
2. **Our dictionary is the source of truth**: `zz_krinik.txt` grows from the audit, generators own their blocks, the audit runs
   after every translation change (stubs → 0, terms → 0 by the glossary). Already started.
3. **Every fix is looked at in the game** (frame) — a translation fix is a layout change (ms0).
4. **Title Case** — keep or switch to sentence case (Russian norm). `[AI]` the choice is left to the owner; one regex pass either way.
5. Later: route B from `README.md` § 3 (rewrite code literals with Mono.Cecil) for the 1 538 code strings.
