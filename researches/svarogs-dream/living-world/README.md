## Пять главных выводов

1. **Так делают все, кто сделал живой мир:** рядом с игроком — полная симуляция, вдали — записи в цифрах на медленном
   такте; переход с буфером, чтобы не мигало на границе (Рейнджеры, A-Life, Starsector, AlifePlus).
2. **Сварогу повезло:** все 6 227 персонажей мира лежат в сцене игры с начала (замер `level1`) — книгу можно вести на всю
   карту; у почти всех есть стабильный `PersonalID`.
3. **Решает группа, положение вдали — по формуле, путь — по грубому графу** (центры участков, поселения, развилки); бой
   вдали — броски силы; экономика — цены дрейфуют к цели; события — там, где героя давно не было.
4. **Хватит простого C# в главном потоке** с бюджетом 0.1 мс в среднем и пределом 2 мс; Jobs без Burst в Mono медленнее,
   Burst недоступен, видеокарта не нужна.
5. **Главные риски изведаны другими:** две расходящиеся модели боя (серия X), вал порождения после перемотки (Warfare),
   провал заданий из-за смерти цели вдали (AlifePlus), порча сохранений (ButterLib) — у каждого есть известное лечение.
