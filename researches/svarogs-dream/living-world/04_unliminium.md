## 1. Что там есть на самом деле

- **Теория игрового ИИ — четыре сжатых конспекта** (`researches/04–07`, по ≈15 КБ): полезность (Utility AI, IAUS, кривые
  отклика, личность как веса), планирование (GOAP, HTN, деревья поведения), поиск (expectimax, MCTS), синтез (BDI, три слоя,
  «ручка ума» 0..4+, одна голова для NPC, уровни детализации).
- **Самое большое — разведка событий и мест мира** (`researches/38`, 3 657 строк, 601 КБ, 68 расшифровок видео, 234
  источника): часы угроз, знамения, отметки мира, таблицы по сезону, возможно лучший каталог приёмов «мир меняется сам».
- **Целеполагание** (`researches/37`, 30 КБ): стратегия → тактика → операция (военная теория, Хосин, OKR, ДОТУ: векторы
  цели, состояния и ошибки).
- **Построено:** автомат боя мобов «АБМ» (`tools/engine/abm.mjs`, 213 строк): 10 повадок, список приоритетов «первое
  подходящее правило», жребий при равенстве, бегство ниже ¼ телосложения, «двойник» — повадка на один ход; гнездо политик
  героя (`tools/ai/policy.mjs`: жадная и случайная); мир на кубиках таблиц событий; стенд с журналом каждого броска и
  повтором партии бит в бит.
- **Не построено:** потребности, векторы личности, скоринг полезности, планировщик, фракции; фазы ИИ 2–7 убраны в архив
  2026-09-18. Канон Unliminium сознательно отвергает полную симуляцию: «Полная симуляция NPC/фракций — слишком сложна для
  стола. Мир живёт через случайные добрые и злые события дня» (`GOAL.md`). У мода стола нет — нам это можно.

## 2. Что переносится в Сварог (приёмы, не цифры)

| Приём | Как в Сварог | Источник в Unliminium |
|---|---|---|
| **Гнездо решений** — мир спрашивает, голова отвечает | у записи книги одна точка `Decide(вид, допустимые действия) → действие`; вдали — дешёвая голова книги, рядом — ИИ игры | `tools/ai/policy.mjs`, `researches/09` |
| **Полезность с компенсацией (IAUS)** | каждое действие путника (идти на рынок, на охоту, в трактир, в лагерь фракции) — произведение кривых отклика с поправкой на число осей; лог вклада каждой оси — «почему он так сделал» | `researches/04` |
| **Личность = веса** | архетипы путника — веса (жадный, осторожный, воинственный, заботливый) в файле данных, а не в коде | `researches/04, 07` |
| **Умные объекты** | торговцы, доски заданий, логова, подземелья, караваны сами «рекламируют», какую потребность закрывают; новое содержимое не требует правки ИИ | `researches/04` (The Sims) |
| **Стек целей** | путник: стратегия (разбогатеть, выжить, долг фракции) → тактика (продать добычу в Баре, чтобы…) → операция (переход, бой, торг) с «готово, когда» и аварийным порогом; перепланирование по событию, не по часам | `researches/37` |
| **Бой по списку приоритетов** | стычки вдали: первое подходящее правило, цели (меньше всего здоровья / сильнейший удар), жребий, бегство ниже ¼, вожак держит стаю; «двойник» ≈10 % — непредсказуемость даром | `tools/engine/abm.mjs`, `ideas/15`, `ideas/22` |
| **Детерминизм и стенд** | одно семя на мир, журнал бросков, повтор, «стенд» без игры: N игровых дней → плотность, смерти, торговля, баланс фракций | EXP-0027/0028 Unliminium, `sim:*` |
| **Учёт притоков и оттоков** | у каждого события знак потока (существо ±1, предмет ±1, золото); приток = отток в равновесии; порождение зависит от числа «едоков» («карта не пуста — она съедена») | `researches/25`, `ideas/47` |
| **Дальний уровень — «шаг судьбы»** | очень далеко — не агенты, а таблица событий по участку в час | `plans/archive/18_uai_phase5_alife.md` |
| **Фракции** | ход фракции раз в день/неделю (WWN), часы войны (Blades), «контракты из симуляции» и «каждый убитый орк — минус воин племени» (Battle Brothers), лестница состояний места (Warband: норма → разграблено → восстановление) | `researches/38` (раздел фракций) |
| **Ограничители** (урок Radiant AI) | жёсткие запреты: не убивать важных для заданий; поражение чаще ведёт к бегству и потере добычи, чем к смерти; правило, кому достаётся добыча, если лагерь разбила третья сила | `researches/04`, `researches/38` |

## 3. Что НЕ переносится

- Ограничения стола (один D100, «не заставлять считать время») и антисимуляционный канон.
- Слой поиска (expectimax/MCTS по чистой модели правил) — дорого на агента, и у Сварога нет чистого движка правил.
- GOAP с A* каждый час на агента — можно, но не нужно: списки приоритетов и HTN дешевле.
- Настроенных чисел нет: ИИ Unliminium не строился, переносятся только формулы и приёмы.
- Карта из 100 клеток без движения существ — для путей бесполезна; книге нужен свой граф участков и дорог.
- Подстройка под силу героя («уровень от сильнейшего героя») — противоречит вкусу владельца «ничто не упирается».

## 4. Тик книги — синтез приёмов (псевдокод исследователя, сверен с `05_architecture.md`)

```
для каждого участка мира (по кругу, в бюджет тика):
  если участок рядом с героем: персонажи материализованы → их ведёт игра; книга только отражает
  иначе если участок очень далеко: бросок таблицы событий участка (знак потока) → порождение/убыль/стычки в цифрах
  иначе для каждой записи участка:
    если операция выполнена / сработала ветка / авария: перепланировать (стек целей)
    действие = argmax по допустимым и «рекламируемым» действиям: компенсация(Π кривая_i(вход_i)) × веса_личности
    применить (переход по графу / бой по списку приоритетов с жребием / торг / задание), записать броски
  ход фракций по своему ритму; часы войны; проверка равновесия потоков
```
