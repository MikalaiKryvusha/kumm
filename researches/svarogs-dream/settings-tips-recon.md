## Mechanics

- Game tooltip = `GameUI.HoverEnabler` on the «?» icon (`circle128` + child `QuestionMarkImage`); `objectToEnable` = the popup with text.
  Placement of game popups — our `QuestionTips.PlaceQuestionTip` (clamped to the label's left edge on settings pages).
- Mod tooltip = `KrinikTip.On(graphic, title, body, null)` (`KrinikTip.cs`) — use it for new «?» (clone an existing «?» icon, drop its HoverEnabler).
- Layout of settings pages — `SettingsLayout.cs` (`LayoutSettingsPage`): «?» is now placed after the control; the new column goes at the
  line of labels (after «Сменить» on Controls), labels shift right by the «?» width + gap.

## What the options do (decompiled `Assembly-CSharp`, `GameSettingsManager`)

| Option | Code | Fact |
|---|---|---|
| Graphic Preset | `SetGraphicPreset` → `GraphicSettings(level)` | High: everything on · Medium: details and quality Medium · Low: details and quality Low, no AO, AA, HDR (shadows and VSync stay on) · Custom: set by hand |
| Details Quality (`TextureQuality`) | `QualitySettings.SetQualityLevel(0..3)` | Unity quality level; what each level holds — read at runtime (`QualitySettings` per level) before writing the text |
| Details Count | `RefreshDetailsCount` | terrain `detailObjectDensity` 1 / 0.66 / 0.33 / 0.15 (grass, small plants); rain particles high/mid/low; `WorldTravelers` off at Very Low; `OptionalDetails` objects off below Medium; soul spawn effect off below High; NavMesh iterations 500/150/100/75 |
| Ambient Occlusion | post-processing `_ambientOcclusion.active` | soft contact shadows in corners |
| Anti Aliasing | `PostProcessLayer.Antialiasing.TemporalAntialiasing` / None | TAA |
| HDR | `mainCamera.allowHDR` | internal HDR rendering, not monitor HDR |
| Shadows | `QualitySettings.shadows = All / Disable` | all shadows on/off |
| Screen Resolution | `Screen.SetResolution`; Auto = `Screen.resolutions[^1]` (largest) | |
| Target Frame Rate | `Application.targetFrameRate` 30/60/75/120/144/999 | ignored by Unity while VSync is on |
| FPS Counter | `fpsCounter.SetActive` | top right corner |
| Full Screen | `Screen.SetResolution(..., isFullScreen)` | |
| Camera - Lower Base Angle | camera pitch 50° instead of 57° (yaw −20°) | |
| Camera - Lower Field of View | FOV 35° instead of 30° — the view gets WIDER (label is misleading) | |
| Brightness | colour grading `postExposure = value/100 × 2` | |
| Volumes | `Get*Volume = global/100 × own/100` | every slider is a share of the global one |
