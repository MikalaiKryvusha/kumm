# `researches/` — a knowledge base on large, hard questions

Notes and distilled conclusions on big, complex questions: research write-ups, accumulated
experience, important reference information won by real work that must not evaporate. One `NN_<name>.md`
per research topic.

**For the owner:** the place to find the deep background of decisions — why an approach was chosen, what was found out
about a hard problem. You can name a topic you want researched.

**For the AI agent:** when a question is big enough that its conclusions should outlive the current task, write
notes here (raw sources → analysis → conclusions/hypotheses). Link to them from the bug/plan/idea that spawned
the research (DRY — don't re-research). Right after the H1 comes the lintable header meta: **Created:** ·
**Parent:** · **Status:** · **Outbound:** (`AGENT_GUIDE.md` → Document header meta). A research
note is a **living reference**, not a closable
task: never `DONE`-tagged, updated as understanding grows.
