## Image types
TAG: ugui.image.types
SOURCE: https://docs.unity3d.com/Packages/com.unity.ugui@1.0/manual/UIVisualComponents.html
SOURCE: https://raw.githubusercontent.com/needle-mirror/com.unity.ugui/1.0.0/Unity-2020.3.18f1/Runtime/UI/Core/Image.cs (L20-72, L843-869, L998-1004)

- **Simple** — "Scales the whole sprite equally."
- **Sliced** — "Utilises the 3x3 sprite division so that resizing does not distort corners and only the center part is
  stretched." Source remark: "For this method to work properly the Sprite assigned to Image.sprite needs to have
  Sprite.border defined." (source) If the sprite has **no border**, `GenerateSlicedSprite` silently falls back to
  `GenerateSimpleSprite` — the whole sprite stretches.
- **Tiled** — "Similar to Sliced, but tiles (repeats) the center part rather than stretching it. For sprites with no
  borders at all, the entire sprite is tiled." Source remark: the generated mesh "will be limited to 16250 quads; if your
  tiling would require more tiles, the size of the tiles will be enlarged"; for efficiency "use a Sprite with no borders
  and with no packing, and make sure the Sprite.texture wrap mode is set to TextureWrapMode.Repeat."
- **Filled** — "Shows the sprite in the same way as Simple does except that it fills in the sprite from an origin in a
  defined direction, method and amount." (bars, radial cooldowns)
- "Set Native Size, which is shown when Simple or Filled is selected, resets the image to the original sprite size."
  (`SetNativeSize()`.)

## Pixels per unit: how many canvas units a sprite pixel covers
TAG: ugui.image.pixels-per-unit
SOURCE: https://raw.githubusercontent.com/needle-mirror/com.unity.ugui/1.0.0/Unity-2020.3.18f1/Runtime/UI/Core/Image.cs (L698-719)
SOURCE: https://docs.unity3d.com/Packages/com.unity.ugui@1.0/manual/script-CanvasScaler.html

(source)
```csharp
public float pixelsPerUnit
{
    get
    {
        float spritePixelsPerUnit = 100;
        if (activeSprite) spritePixelsPerUnit = activeSprite.pixelsPerUnit;
        if (canvas) m_CachedReferencePixelsPerUnit = canvas.referencePixelsPerUnit;
        return spritePixelsPerUnit / m_CachedReferencePixelsPerUnit;
    }
}
protected float multipliedPixelsPerUnit { get { return pixelsPerUnit * m_PixelsPerUnitMultiplier; } }
```
So **1 sprite pixel = `referencePPU / (spritePPU × pixelsPerUnitMultiplier)` canvas units.** With the usual sprite PPU 100
and CanvasScaler `referencePixelsPerUnit` 100 (default), 1 sprite pixel = 1 canvas unit. CanvasScaler manual: "If a sprite
has this 'Pixels Per Unit' setting, then one pixel in the sprite will cover one unit in the UI."

## 9-slice border thickness and pixelsPerUnitMultiplier
TAG: ugui.image.ppu-multiplier
SOURCE: https://raw.githubusercontent.com/needle-mirror/com.unity.ugui/1.0.0/Unity-2020.3.18f1/Runtime/UI/Core/Image.cs (L1025-1035, L1097-1100)
SOURCE: https://docs.unity3d.com/2020.3/Documentation/ScriptReference/Sprite-border.html

(source) Sliced: `adjustedBorders = GetAdjustedBorders(border / multipliedPixelsPerUnit, rect)`; Tiled: tile size
`(spriteSize - borders) / multipliedPixelsPerUnit`. `Sprite.border` is in sprite pixels, "X=left, Y=bottom, Z=right,
W=top".
- On-screen corner size (canvas units) = `border_px × referencePPU / (spritePPU × pixelsPerUnitMultiplier)`.
- `pixelsPerUnitMultiplier = 2` → corners and edges half as thick; `0.5` → twice as thick. The center stretch is
  unaffected. This is the knob for "same frame art, thinner border" (CSS `border-image-width`).
- Changing `localScale` also scales the border; changing width/height does not.
```csharp
img.type = Image.Type.Sliced;
img.sprite = frameSprite;              // frameSprite.border = (12, 12, 12, 12) px, PPU 100
img.pixelsPerUnitMultiplier = 2f;      // draws 6-unit corners on a 100-refPPU canvas
img.fillCenter = true;
```

## Borders bigger than the rect shrink proportionally
TAG: ugui.image.border-shrink
SOURCE: https://raw.githubusercontent.com/needle-mirror/com.unity.ugui/1.0.0/Unity-2020.3.18f1/Runtime/UI/Core/Image.cs (L1344-1374)

(source) `GetAdjustedBorders`: "If the rect is smaller than the combined borders, then there's not room for the borders at
their normal size. In order to avoid artefacts with overlapping borders, we scale the borders down to fit."
```csharp
float combinedBorders = border[axis] + border[axis + 2];
if (adjustedRect.size[axis] < combinedBorders && combinedBorders != 0)
{   borderScaleRatio = adjustedRect.size[axis] / combinedBorders;
    border[axis] *= borderScaleRatio; border[axis + 2] *= borderScaleRatio; }
```
A pill/round-corner sprite on a box thinner than its two borders gets squashed corners (ellipses instead of circles):
make the box at least `left+right` wide and `bottom+top` tall in units, or raise `pixelsPerUnitMultiplier`.

## Image preferred size in a layout = sprite size
TAG: ugui.image.preferred-size
SOURCE: https://raw.githubusercontent.com/needle-mirror/com.unity.ugui/1.0.0/Unity-2020.3.18f1/Runtime/UI/Core/Image.cs (L1700-1755)
SOURCE: https://raw.githubusercontent.com/Unity-Technologies/UnityCsReference/2020.3/Runtime/2D/Common/ScriptBindings/SpriteDataUtility.cs (L27-34)

(source)
```csharp
public virtual float preferredWidth
{   get {
        if (activeSprite == null) return 0;
        if (type == Type.Sliced || type == Type.Tiled)
            return Sprites.DataUtility.GetMinSize(activeSprite).x / pixelsPerUnit;   // border.x + border.z
        return activeSprite.rect.size.x / pixelsPerUnit;
} }
public virtual float minWidth { get { return 0; } }
public virtual float flexibleWidth { get { return -1; } }
public virtual int layoutPriority { get { return 0; } }
```
Note: preferred uses `pixelsPerUnit`, **not** the multiplier. A Simple 64×64 icon inside a controlling layout group asks
for 64×64; a Sliced background asks for only its border sum. Mixed children (icon + background) therefore get different
bases — override with a LayoutElement when sizes must be uniform.

## Creating a 9-slice sprite at runtime
TAG: ugui.image.runtime-sprite
SOURCE: https://docs.unity3d.com/2020.3/Documentation/ScriptReference/Sprite.Create.html

```csharp
// tex: a Texture2D loaded from the mod folder (e.g. ImageConversion.LoadImage)
Sprite s = Sprite.Create(tex, new Rect(0, 0, tex.width, tex.height),
                         new Vector2(0.5f, 0.5f), 100f, 0, SpriteMeshType.FullRect,
                         new Vector4(12, 12, 12, 12));   // border: left, bottom, right, top (px)
img.sprite = s; img.type = Image.Type.Sliced;
```
Parameters (API): `pixelsPerUnit` — "The number of pixels in the sprite that correspond to one unit in world space."
`border` — "The border sizes of the sprite (X=left, Y=bottom, Z=right, W=top)." `meshType` — "selects whether `FullRect`
or `Tight` is used". Use `FullRect` for UI sprites (the Image only uses the sprite's own mesh when `useSpriteMesh` is on).
General practice, not from a fetched page: `tex.wrapMode = TextureWrapMode.Clamp` for frames (Repeat only for Tiled
centres, as the Tiled remark above says), bilinear filtering.

## UI/Default shader: premultiplied output, no colour-space code
TAG: ugui.image.ui-default-shader
SOURCE: https://raw.githubusercontent.com/chsxf/unity-built-in-shaders/2020.3/Shaders/DefaultResourcesExtra/UI/UI-Default.shader (L41-46, L105-124)

(source; chsxf archive of Unity's official built-in shader zips, 2020.3 branch)
```
Cull Off  Lighting Off  ZWrite Off  ZTest [unity_GUIZTestMode]
Blend One OneMinusSrcAlpha
...
OUT.color = v.color * _Color;                                        // vertex colour (Graphic.color) × material tint
half4 color = IN.color * (tex2D(_MainTex, IN.texcoord) + _TextureSampleAdd);
#ifdef UNITY_UI_CLIP_RECT  color.a *= m.x * m.y;  #endif               // RectMask2D
#ifdef UNITY_UI_ALPHACLIP  clip (color.a - 0.001); #endif
color.rgb *= color.a;                                               // premultiply in the shader
return color;
```
The 2020.3 UI shader contains no gamma/linear conversion; in a Linear project the vertex colour reaches it already
linearised by the canvas (see `color.linear.ui-vertex-colors`). Blending is premultiplied "over", performed in the
framebuffer's colour space.
