# Conan Exiles — custom user music by game situation: existing mods and alternatives

**Created:** 2026-11-06 · **Parent:** the owner's words «для игры есть моды по интеграции музыки пользователя?» · «чтобы были папку, куда закидваются треки под определённые сценарии в игре» · **Status:** research done (web only; nothing downloaded or run; no in-game recon yet) · **Outbound:** the verdict to the owner as a Russian copy (section "Verdict — Russian copy")

Method note. Steam Workshop items were read through the public Steam Web API `ISteamRemoteStorage/GetPublishedFileDetails` (title, created/updated dates, size, subscriptions, tags, the author's description); the HTML item pages answered 429/500 to automation. Workshop search used the public browse page (`appid=440900`; terms: music, soundtrack, ambient, combat music, jukebox, radio, mp3, playlist, boombox, bard, song, sound overhaul; ~680 ids resolved, ~45 music-related). Nexus Mods was searched through its public GraphQL API (game domains `conanexiles` and `conanexilesenhanced`) and pages read with curl. Dates are the sites' "last updated" (UTC). The Workshop tag `Enhanced` marks the UE5 line (Conan Exiles Enhanced, shipped 2026-05-05); `Legacy` marks UE4 — "UE4-compiled mod paks don't load in a UE5 game binary" (low.ms, see Sources).

## How the game plays music (what is known)

- Engine-native UE audio, not Wwise/FMOD: music lives under `sound\music` as **Sound Cues**; combat music is tiered by enemy difficulty — `sound\music\combat1\CombatMusic_Easy_Cue` etc. Each cue = several Wave Player nodes → a Random node → Output; adding a track = another Wave Player on the Random node (Bambouclat, Funcom forum 2021). The Nexus 95 description adds: up to 32 songs "per area or per level of difficulty of your enemy", the very-easy tier (rabbits, ostriches) has no music.
- Selection goes through a **Sound Stage Table** (a data table; rows like `GotC_MUS_Universal` added by a map mod; a later mod's row merge overrides it) — GotC Music Killer, 2025-12.
- Situation cues have names, e.g. `Music_death_Cue` (death) — still present in Enhanced (DramaBGone Enhanced, 2026-05).
- In-game settings: turning ambient music off still leaves combat music (forum 2021) — the two are separate channels; location music in Sepermeru etc. is area-triggered (2019 bug thread: "location music … didn't trigger", combat music still worked).
- Not found in any source: the class that runs the music (manager/component), how night/base/boss/dungeon are distinguished, whether Enhanced moved anything to MetaSounds. Our build is UE 5.8 (local game map); an object dump through our UE4SS remote would answer this in one session.

## Verdict

**No** — no Conan Exiles mod (Legacy or Enhanced) lets the player drop their own files into folders mapped to game situations. **Partly** — the nearest are: (1) soundtrack replacers (Custom Music Overhaul [Enhanced] is the live one) — situational, but the author's fixed tracks; changing them means cooking a pak in the Dev Kit; (2) in-world players — Melodie Box plays the user's MP3s, but only by internet URL and only around a placed box; Music Barrel takes songs only as cooked paks via its API. The exact requested pattern exists in another UE game: Palworld's "Area specific backround Music" (UE4SS, per-area / per-dungeon / per-enemy-type folders, mp3/ogg/wav/flac, no music shipped).

## Cheapest path to build ourselves

A client-side UE4SS mod with no pak: Lua detects the situation, an audio player plays files from `…\ue4ss\Mods\KrinikMusic\music\<situation>\` (combat, combat_boss, explore_<biome>, night, base, dungeon, menu, death, with fallback to a generic folder, random pick, crossfade, and a short hold to stop combat/explore flapping), and the game's own music is silenced by its music volume / sound class while ours plays. The cheapest situation source is the game itself: hook the moment its music system starts a cue / picks a Sound Stage row and map that cue or row name to a folder — the game then decides "combat easy/hard, area, death" for us, and we add only what it lacks (night from the time of day, base from being inside our own building zone, boss from the target class). Playback outside the engine thread, as M4 Music (external host) or the Subnautica 2 jukebox / Palworld Area Music (native DLL) do, keeps the game thread free and decodes mp3/ogg/flac without cooking. First step before any code: one recon session with our UE4SS remote — find the live music component/manager, the Sound Stage table and the cue names in 3.0.1.

## Verdict — Russian copy

Готового мода «папки под сценарии со своей музыкой» для Конана нет — ни для старой, ни для новой (Enhanced) версии. Есть близкое. Первое — замены саундтрека: живая из них Custom Music Overhaul [Enhanced], она играет по ситуациям игры, но только треки автора; свои треки туда кладутся лишь пересборкой пака в Dev Kit. Второе — проигрыватели-предметы. Melodie Box играет твои MP3, но только по ссылке из интернета и только рядом с поставленной коробкой. Music Barrel принимает песни только собранными паками. Ровно такой мод, как ты описал, есть в Палворлде («Area specific backround Music»: папки на каждую область, подземелье и тип врага, mp3/ogg/wav/flac, своей музыки в нём нет). Для Конана его можно сделать нашим UE4SS-модом без пака: ловим, какую музыку игра включает в данный момент (бой, область, смерть), добавляем ночь, базу и босса, глушим родную музыку и играем случайный трек из нужной папки с плавным переходом.
