## Вектор цели

**Боль.** Dev Kit (169 ГБ) лежит на `F:\CEDevKit` с 10.09 нетронутым, и всё, что мы знаем об
игре, добыто по ИМЕНАМ файлов и по журналу: содержимое паков сжато Oodle и не читается. Из-за
этого три заказа владельца стояли как «невозможно»: своя кривая опыта, русификация, точные пары
конфликтов модов.

**Куда идём (тип цели — Achieve).** Агент читает правду игры из исходников Dev Kit одной
командой и собирает собственный pak-мод одной командой — без окна редактора, без участия
владельца, с проверкой в живой игре по журналу. Интерактивный канал в живой редактор (CLI, при
пользе — MCP) — второй очередью, когда безоконная часть работает.

## Что Dev Kit даёт — коротко (подробно в разведке)

1. **154 ГБ несжатых исходников игры** — каждая таблица, блюпринт, виджет, строка локализации.
   Кривая опыта найдена и **прочитана 12.09 за 1 мин 52 с безоконным запуском**:
   60 уровней, `LevelStart`/`LevelEnd`, порог 12-го уровня — 61 825 (то же число, что снято в
   игре 10.09). Файл: `researches/conan-devkit/DT_ExperienceSystemLevel.csv`.
2. **Штатная сборка модов целиком в исходниках** (`UE4/Build/ModDevKit.Automation/BuildMod.cs`):
   Cook → Pak → FinalPak, три платформы, Oodle. Знаем точные командные строки, которые нажимают
   кнопки редактора, и ключ `-ScriptDir`, без которого сборка «не находит script module records».
3. **`UnrealPak.exe` из комплекта читает любой пак мода** вместе с Oodle: проверено на
   `ChestLabels.pak` — список, распаковка обёртки, список внутреннего контейнера. Это заменяет
   наш самописный разбор `.utoc` и открывает `modinfo.json` каждого мода.
4. **Безоконный редактор с Python** (`UnrealEditor-Cmd.exe -run=PythonScript … -NullRHI`) —
   канал для всех «прочти правду» инструментов. Первый запуск не компилирует шейдеры: 2 минуты,
   а не 30–60 (это цена только ОКОННОГО запуска).
5. **Каналы в живой редактор есть, MCP к киту никто не прикручивал:** Python remote execution
   (UDP+TCP), Remote Control API (HTTP/WebSocket), `CmdLink.exe`, заглушка экспериментального
   `AIAssistant` Epic. Готовые MCP-серверы сообщества — предмет веб-разведки (`researches/conan-devkit/web-recon.md`).

## Фазы

### Фаза 0 — Чтение: безоконный читатель игры 🟢 спланирована
- **Цель фазы:** правда игры и правда модов читаются командой, а не догадкой (A1, A2).
- **Инструменты:** `devkit-run.ps1` (запуск командлета без окна, журнал, код возврата, страж
  места на диске и версии) · `dt-export.py` (таблица → CSV, список таблиц) · `pak-inspect.py`
  (обёртка над `UnrealPak -List/-Extract`, каталог `modinfo` всех модов, матрица «кто везёт
  ванильные пути») · страж версий кит/игра.
- **Ворота:** A1 и A2 зелёные; матрица переопределений посчитана и лежит в паке.
- **Операционный план:** `plans/07_epic06_phase0_chtenie.md`.

### Фаза 1 — Первый собственный pak-мод без окна 🔲
- **Цель фазы:** мод из скелета собирается одной командой, раскатывается движком KUMM и
  монтируется игрой (A3, A4).
- **Инструменты:** `mod-skeleton.py` (папка мода, `modinfo.json`, `Local/CookInfo.ini`) ·
  `build-mod.ps1` (`RunUAT BuildMod` тремя стадиями, `-ScriptDir`, проверка выхода) ·
  сторож журнала игры (`MountMod`, `ModCompat`, `ValidateMod`).
- **Тестовый груз:** мод-переопределение одной таблицы данных. Какой именно и с какими
  числами — развилка 1 (владелец).
- **Главный риск (а):** кит новее игры (CL 374980 beta против CL 373655), а игра по своим же
  строкам отвергает пакет НОВЕЕ себя (*«Package is unloadable … Version is too new /
  LicenseeVersion is too new / Custom version is too new»*, *«Incompatible Mods Detected»*).
  Правило: точное совпадение не нужно, нужно «не новее». **Шаг 0 фазы — офлайн-сверка:** блок
  версий в `.uheader` мода, который грузится сегодня (Chest Labels, ревизия кита 1001), против
  блока версий пакета, скукованного нашим китом на пустом моде. Совпало — фаза идёт; не
  совпало — ждать обновления игры до ветки кита либо искать кит релизной ветки. Дальше —
  выброшенное сохранение; откат — одна строка `modlist.txt`.
- **Готовый образец (MIT):** `jvdberg1/exileforge` — PowerShell + Unreal-Python CLI, строит
  мод потолка уровня без окна на `5.6.1-366792`; проверенная строка
  `RunUAT.bat -NoCompile BuildMod -Mod=<М> -Project="<кит>/UE4/ConanSandbox.uproject" -Cook -Pak
  -Compress -ScriptDir="<кит>/UE4/"` (**`-ScriptDir` — корень `UE4/`**, без него «Failed to find
  command BuildMod»). Брать как отправную точку, не переписывать с нуля.
- **Ворота:** A3, A4; снимок «Хар-ки» с ожидаемым числом опыта.

### Фаза 2 — Локализация 🔲
- **Цель фазы:** ответить на пункт 6 плана 04 фактами: кто ломает русский, что без перевода,
  и собрать мод-перевод по штатному пути игры (A5).
- **Инструменты:** `loc-audit.py` (манифесты локализации 18 целей против `ru/*.locres`; ассеты
  модов с `FText` без ключа) · конвейер `GatherText`/`.locres` для мода-перевода.
- **Ворота:** A5; одна переведённая строка мода видна в игре.

### Фаза 3 — Конфликты как таблица, а не впечатление 🔲
- **Цель фазы:** MASTER_PLAN, фаза 3 (совместимость) — из распакованных контейнеров модов
  строится матрица «ассет → кто везёт → кто побеждает» (A6); движок KUMM получает
  игронезависимый источник конфликтов (вывод `UnrealPak -List`).
- **Ворота:** A6; `-DryRun` называет спорные строки по модам.

### Фаза 4 — Живой редактор: CLI, потом MCP 🔲
- **Цель фазы:** интерактивный канал в запущенный редактор для задач, где командлет слишком
  медленный (каждый запуск — ~2 мин инициализации): `devkit-remote.py "<python>"` через
  remote execution; оценка готовых MCP-серверов по веб-разведке.
- **Что известно из разведки (`researches/conan-devkit/web-recon.md` §8):** в ките лежат
  ЗАГЛУШКИ без бинарников — Epic «Unreal MCP» (`ModelContextProtocol`), AI Assistant, Remote
  Control, CmdLinkServer; собрать их нельзя (installed build без компилятора). Живой канал один —
  Python remote execution (UDP `239.0.0.1:6766` + TCP `127.0.0.1:6776`). Кандидаты MCP без
  компиляции плагина: `radial-hks/mcp-unreal-server` (чистый remote-exec, Apache-2.0);
  прекомпилированные под 5.8 (`GenOrca/unreal-mcp`, `ChiR24/Unreal_mcp`) — риск несовпадения
  ABI с лицензиатской 5.8.2. Все, кому нужен свой C++-плагин (`chongdashu/unreal-mcp`,
  `UnrealGenAISupport`, `unreal-ai-connection`) — мимо.
- **Условие:** ОКОННЫЙ запуск редактора — плановое событие с владельцем (30–60 мин шейдеров,
  окно отбирает экран удалённого стола). Развилка 2.
- **Ворота:** одна команда из чата возвращает ответ живого редактора за ≤ 5 с.

## Развилки — решения владельца (в интервью, здесь только перечень)

1. **Тестовый груз фазы 1 и кривая опыта.** Владелец сказал 10.09: «хочу БЕЗ потолка уровня…
   кривая пологая или линейная вообще». Ванильная таблица — 60 уровней, 7.6 млн опыта до
   вершины. Варианты: (A) свой мод кривой поверх MrS Level 1000 — какая форма и какие числа;
   (B) оставить MrS, тестовым грузом взять безобидную таблицу (`DT_FeatsPerLevel`);
   (C) сперва прочесть таблицу MrS из его пака и сравнить. Имя мода — тоже его слово.
2. **Оконный запуск редактора** — когда владельцу удобно отдать экран на час (фаза 4).
3. **USN-журнал на `F:`** — редактор просит `fsutil usn createJournal F: m=0x40000000` из
   повышенной консоли ради быстрого пересканирования; это настройка тома — его решение.
