## Критерии приёмки эпика

Мерило — механизм, а не впечатление (разведка §4.1): каждое утверждение «мир живёт» доказывается журналом мода.
[AI] Числа-цели ставятся после замеров фазы 0 — до них стоят шкала и способ замера, а не выдуманная цифра.

1. **Ушёл — вернулся.**
   - Ситуация. Герой в своей деревне, мод включён, сохранение владельца.
   - Действие. Герой уходит за пределы всех чужих деревень и проводит там 3 игровых дня.
   - Результат. В журнале мода за эти 3 дня — сделки купцов, хотя бы одна стычка на дороге, смена цены хотя бы в одной
     деревне, хотя бы одно решение субъекта, вызванное чужим действием; вернувшись, герой видит у торговца другой товар.
   - Проверка. `ledger stats --days 3` до и после; цена товара у торговца деревни — `ledger price <деревня> <товар>`.
2. **Петля замкнута.** Шкала — число цепочек «действие → изменение мира → действие другого субъекта» длиной ≥ 3 за игровую
   неделю; способ — разбор журнала `ledger chains --week`; цель — после замера фазы 2.
3. **Общество живёт.** Шкала — союзы и вражды, возникшие между субъектами сами (не заданные данными), за игровой сезон;
   способ — `ledger alliances --season`; цель — после фазы 4.
4. **Всё видно.** У каждой системы мода есть хотя бы один выход к игроку (глашатай, таверна, доска, цены, гости, рейтинг)
   — таблица «система → канал» в документе приёмки; пустая клетка — дефект.
5. **Цена кадра.** FPS в деревне игрока и у чужой деревни не ниже замера без мода больше чем на допуск; замер — PresentMon,
   база — фаза 0.
6. **Сохранение.** После сохранения и загрузки книга мира совпадает с собой до сохранения (сверка дампа).
6а. **Учёт сходится.** Для каждой деревни и каждого товара за игровой день: запас вчера + произведено + привезено −
   съедено − увезено − испорчено − сношено = запас сегодня. Способ — `ledger balance --day`; цель — **ноль расхождений**, любое
   ненулевое — дефект (вещь из воздуха). Каждый NPC мира ест; голодный NPC — запись в журнале с причиной.
7. **Игра цела.** Главные и семейные квесты проходятся: мод не трогает квестовых NPC и предметы (список разрешённых).

## Устройство — модули и проводка

### Почему один рантайм-мод, а не россыпь

Между Lua-модами UE4SS ходят только простые «общие переменные» — таблицу мира через них не передать (разведка §3.4,
сверено по документации). Поэтому вся симуляция — **один мод UE4SS** с модулями внутри; каждый модуль включается и
выключается настройкой — это и есть «мод» для игрока. Данные — тексты, реплики, таблицы — едут **отдельными pak-модами**.

**Правила проводки.**
1. Системы не вызывают друг друга. Их контракт — **книга** (общее состояние), **шина** (события) и **часы** (такт).
   Новая система подключается без правки старых — так растёт глубина «как в Kenshi».
2. Книга — единственный писатель состояния мира вдали; мост «запись ⇄ актёр» — единственный, кто трогает актёров игры.
3. Каждый субъект решает через мозг: система спрашивает «что делать?», мозг отвечает по характеру и цели.
4. Всё, что трогает игру, — на игровом потоке (разведка §3.4).
5. Каждое событие шины пишется в журнал — из журнала собираются критерии приёмки и витрина.

### Как по проводке проходит цепочка купца (образец владельца)

`Часы: день` → **Хозяйство** считает склады, цена соли в деревне A низкая → **Воля** купца: «прибыль» → **План**: купить в A,
везти в B → **Торговля** пишет сделку (склад A −, кошелёк −) → шина «сделка» → **Карта** даёт путь, купец в дороге →
**Разбой**: шайка у дороги, её Воля «добыча» → **Стычки**: вымогательство, часть груза — шайке → шина «засада» →
**Отношения**: купец запомнил шайку → **Летопись**: «на дороге A–B ограблен купец» → **Слухи** в таверне → герой рядом —
**Мост** материализует шайку настоящими бандитами игры → герой убивает — добыча законна, репутация (**Разбой и закон**) →
купец доезжает, **Торговля**: продажа в B, склад B +, цена в B падает → **Рейтинг** купцов обновлён.

- **(а) Высокие — строим защиту.** Крэш спавна UE4SS (#527) — фаза 0 первой же проверкой, спавн функциями игры. Поиск пути

  Fortress) — журнал и стенд «прокрутить N дней»; горячая перезагрузка UE4SS роняет игру — выключена.
- **(в) Помнить.** Патч игры поменяет блюпринты — оглавления менеджеров (`tools/bp-outline.py`) сверять после каждого патча;
  ключ pak может смениться — `tools/find-aes-key.py`.
