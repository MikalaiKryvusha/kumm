## Вектор цели

**Боль.** Мод перекрашивает окна ПОСЛЕ того, как игра их построила (обход по таймеру, крючки по одному, вёрстка по замеру) —
каждый новый элемент первые кадры показан в виде игры: мигание при смене вкладки, раскрытии квеста, кнопках, подсказках.
Владелец находил эти места по одному весь вечер.

**Куда идём (Achieve).** Новый элемент любого окна рождается сразу в нашем виде: мод один раз переделывает ОБРАЗЦЫ (префабы),
вёрстку держат якоря и раскладка Unity, крючки — только там, где игра красит на ходу, и в тот же кадр. Обход по таймеру — убран.

## Как устроено в игре (разведка по коду 2026-10-06, ilspycmd)

- `QuestsListUI` держит образцы `questPrefab` и `questDesctiptionPrefab`; `PopulateQuestsUI` (зовёт `OnEnable`) удаляет старые
  строки `Destroy` — удаление в конце кадра, в кадре постройки старые и новые стоят в раскладке вместе — и создаёт копии,
  затем красит `questType`, `borderImageLeft/Right` по виду квеста.
- Раскрытие — `QuestHeaderUI.OpenCloseQuestInfo` → `questInfoBox.SetActive(true)`: описание создано заранее, скрытым.
- Отслеживание — `QuestDescriptionUI.TrackQuest` → `questManager.RefreshQuestUI()` (перестройка списков).
